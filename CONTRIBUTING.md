# Contributing

Thanks for your interest in RouteShift.

1. Fork the repository and create a focused feature branch.
2. Keep personal coordinates, device identifiers, generated GPX files, and secrets out of commits.
3. Test changes on macOS and, for device-facing changes, on a device you are authorized to test.
4. Keep pull requests small and explain the behavior changed and how it was tested.
5. Do not submit features whose primary purpose is fraud, covert tracking, access-control bypass, or deception.
